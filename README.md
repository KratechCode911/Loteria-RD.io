# 🇩🇴 Loterías RD

Plataforma web dedicada a la consulta de resultados de las principales loterías de República Dominicana y otros sorteos relevantes.

El proyecto permite consultar resultados actualizados, visualizar estadísticas, revisar el historial de sorteos y analizar los números obtenidos.

## 🚀 Características

- 📊 Resultados de loterías en tiempo real
- 🎯 Resultados de múltiples sorteos y operadores
- 📅 Historial de resultados
- 🔎 Buscador de números y sorteos
- 📈 Estadísticas y análisis de resultados
- 🔥 Números más frecuentes
- ❄️ Números menos frecuentes
- 📱 Diseño responsive para móviles, tablets y computadoras
- 🔄 Actualización automática de resultados
- 🌐 API REST para consumir los resultados
- ⚡ Integración con Supabase
- 🗂️ Organización automática de los sorteos
- 🔔 Arquitectura preparada para futuras notificaciones
